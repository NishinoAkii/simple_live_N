# 界面语言和翻译文件

App 内置简体中文、繁体中文、英文，在“我的 → 外观设置 → 语言”里选，也可以跟随系统。
其他语言用翻译文件加进来，不用改 App。

## 翻译文件

一个 UTF-8 的 JSON 文件。左边是简体中文原文，右边是译文：

```json
{
  "@@code": "ja",
  "@@name": "日本語",
  "设置": "設定",
  "共 {count} 条": "全 {count} 件",
  "关注##tab": "フォロー中"
}
```

- `@@code`：语言代码，如 `ja`、`de`、`pt-BR`。系统语言和它一样时，“跟随系统”会用这份翻译。
  不写时用文件名（`ja.json` 就是 `ja`）。不能是 `zh-Hans`、`zh-Hant`、`en`。
- `@@name`：这种语言自己的写法，显示在语言列表里。
- `{count}` 这样的花括号是占位符，运行时换成具体的值。译文里要原样保留，位置可以挪。
- 带 `##` 的键：同一个中文词在两个地方要译成不同的词时才有，`##` 后面是用在哪里
  （`##tab` 标签页，`##verb` 句子里的动词，`##gift` 礼物名，`##badge` 身份牌子）。
  不单独翻译这一条时，会用不带 `##` 的那条。
- `万`、`亿`：数字的单位。有这类单位的语言照译（日文 `万`、`億`），数字显示成 `1.2万`；
  没有的语言把 `万` 译成 `K`，数字显示成 `12.3K`、`1.2M`。
- `、` `，` `；` `：`：拼句子用的标点，英文是 `", "`、`", "`、`"; "`、`": "`（注意空格）。
- 没翻译的句子显示英文，英文也没有的显示简体中文。

模板在“语言 → 导出翻译模板”：里面是全部句子，右边先填着英文，改成你的语言就行。

## 加到 App 里

在“语言”页里：

- 导入翻译文件：选本机的 `.json` 文件。
- 从网址下载：填文件的网址。GitHub 网页上的文件地址可以直接填。
  下载的翻译旁边有“重新下载”，文件更新后点一下。
  网址也可以指向一份清单，App 会列出来让你选：

  ```json
  {"languages": [{"code": "ja", "name": "日本語", "url": "ja.json"}]}
  ```

  `url` 可以写相对清单的地址。
- 导入的翻译会跟着 WebDAV 同步到其他设备。

## 写代码时

源码里直接写简体中文，后面加 `.t`；句子里有变量时用占位符和 `.tf`：

```dart
Text("复制弹幕".t)
SmartDialog.showToast("共 {count} 条".tf({"count": list.length}));
```

- 中文原文就是翻译表的键，改了原文要同时改 `assets/lang/` 里两张表的键。
- 常量（`const`、默认参数、枚举的参数）里不能用 `.t`：写成 getter，或者在显示的地方再 `.t`。
- 拿来比较、存进数据库、发给平台的文字不要翻译（如关注分组的“全部”、礼物的“开通”）。
  它们保持简体中文，显示时才 `.t`。判断出错原因时不要比较报错文字里的几个字。
- 核心库（simple_live_core）里同样用 `.t` / `.tf`，App 启动时把语言表接到 `CoreText.lookup` 上。
- `test/i18n_test.dart` 会检查两张内置表的占位符和格式。
